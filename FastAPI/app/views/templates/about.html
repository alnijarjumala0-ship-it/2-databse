About FastAPI

Welcome to FastAPI

A complete backend application built with FastAPI following strict MVC architecture.

This application provides a robust foundation for building scalable web services with:

MVC Architecture

Strict separation of Models, Views, and Controllers for maintainable code.

Dual Database

PostgreSQL for relational data and MongoDB for logs and analytics.

Secure Auth

JWT-based authentication with access and refresh tokens.

High Performance

Built on FastAPI with async support for maximum throughput.

Technology Stack
  • FastAPI 0.109+
  • SQLAlchemy 2.0+ with asyncpg
  • Motor/PyMongo for MongoDB
  • Pydantic for data validation
  • SQLAdmin for admin dashboard
  • Bootstrap 5 for UI
